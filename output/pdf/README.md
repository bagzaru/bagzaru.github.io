# 포트폴리오 PDF

채용 사이트 제출용: `portfolio_baek_seunghoon.pdf`

`백승훈_포트폴리오.pdf`도 현재 동일한 내용이다. 두 파일 모두 제작용 로컬 서버 링크를 제거했다. 로컬 링크를 제거한 이전 제출용 버전은 사용자가 넥슨 채용 사이트 업로드 성공을 확인했다.

최근 갱신: 졸업 예정일을 `2027.02(예정)`으로 반영하고 AI 움직임 개선·넉백 설명의 오타를 수정했다. 직전 제출용 PDF와 비교하여 25페이지 중 2·9·10쪽의 텍스트가 변경되었다. 이전에 갱신한 6쪽 타격 판정 설명도 유지한다. 변경 페이지의 렌더링, 웹 전용 표지 안내 제외, 공개 HTTPS 링크 41개를 재확인했다.

## 2026-09-07 호환성 검토

- PDF 1.4, 25페이지, 8,156,951바이트. 암호화·JavaScript·자동 실행 동작·첨부 파일 없음.
- 글꼴과 이미지가 PDF에 포함되어 있으며 외부 파일을 읽는 스트림 참조 없음. 본문을 보는 데 별도 글꼴 설치나 인터넷 연결이 필요하지 않음.
- 클릭 가능한 링크 41개는 모두 공개 HTTPS 주소. 로컬 서버 주소·Windows 파일 경로·만료되는 미디어 URL 없음.
- 링크 정리 전후 모든 페이지의 렌더링 결과가 동일함을 Poppler/Pillow로 확인.
- 웹 배포 빌드를 로그인·캐시 없는 Chromium에서 1440×900, 390×844로 각각 18페이지 검사. 이미지 누락, 영상 오류, 가로 넘침, JavaScript 오류 없음. 모바일 목차 이동 정상.
- 웹 본문 열람에 필요한 이미지·영상·글꼴·미리보기는 배포 파일에 포함됨. 검사 중 외부 서비스 요청 없이 전체 페이지 표시·영상 자동 재생 성공.
- 실제 GitHub Pages 자기소개 주소 정상 응답, 로컬 배포 빌드와 같은 JavaScript 파일 사용 확인.
- 외부 링크 32개 정상 HTTP 응답. Notion 문서 22개는 인증 없이 본문 데이터 접근 확인, DevLog와 Google Drive 자료는 새 브라우저 세션에서 내용 표시 확인. Steam 일부 링크는 연령 확인 화면으로 이동함.
- 기존 자동 테스트 14개 및 프로덕션 빌드 통과.

검증 범위는 Windows의 Chromium 및 Poppler다. macOS Preview, Safari, Firefox와 실제 모바일 기기에서 직접 검사한 결과는 아니다. 외부 링크는 인터넷 연결이 필요하며 각 서비스의 공개 설정과 접속 정책에 영향을 받는다. PDF의 영상은 정지 이미지다.

## 다시 만들기

`node scripts/export-pdf.mjs`로 한글 파일명 PDF를 생성한다. 웹 원본을 변경하지 않는 독립 사본에서 내보내며 사진 원본 링크를 제외한다.

`pypdf`가 설치된 Python으로 다음 명령을 실행하면 제출용 사본을 갱신할 수 있다.

```text
python scripts/remove-local-pdf-links.py output/pdf/백승훈_포트폴리오.pdf output/pdf/portfolio_baek_seunghoon.pdf
```

PDF 내보내기 스크립트의 Playwright/Chromium 경로는 현재 제작 환경 기준이다. 다른 PC에서 재생성하려면 해당 환경에 맞는 런타임 설정이 필요하다. 이미 생성된 PDF나 배포된 웹을 열람하는 데에는 이 제작 도구가 필요하지 않다.
