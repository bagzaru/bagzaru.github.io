### 소개
2023-1학기 '오픈소스 소프트웨어 프로젝트' 과목 과제로 4인 팀으로 GUI로 Git을 관리할 수 있게 하는 프로그램을 구현하였습니다.

JGit 라이브러리를 통해 Git 명령어를 Java에서 실행가능하게 구현, 커밋 그래프 구현, 그외 기타 이벤트 구현을 담당하였습니다.

Git을 활용한 협업을 공부하며 GUI 프로그램을 제작하였습니다.
